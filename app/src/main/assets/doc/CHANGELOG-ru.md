# v1.0.0

###### 2026/09/25

* `Подсказка` Предварительная версия 1.0.0. API задач и входы интерфейса реализованы; результаты аудита P7 записаны. Проверки выпуска и публикация P8 еще не завершены. Пройденные случаи и ограничения см. в [ROADMAP.md](https://github.com/SuperMonster003/AutoJs6-Plugin-AI-Agent/blob/master/ROADMAP.md).
* `Подсказка` Требуются Android 7+, AutoJs6 6.8.0 / build 5293+ для API задач и включенный 3-Stone AI с настроенной моделью. OCR необязателен. Сам протокол подключения требует хост build 5289+.
* `Функция` Панель задач на естественном языке с вопросами, прогрессом, остановкой и результатами; необязательный плавающий ввод, обмен текстом, ярлыки пресетов и голосовые черновики
* `Функция` API ai.agent для создания задач, событий, запросов, ответов и отмены, включая detached и доступ к результатам/контексту зарегистрированных скриптов
* `Функция` Скрипты project.json / @agent с поиском, проверкой и значениями параметров по умолчанию, запросом недостающих значений, подтверждением, ограниченным выполнением и структурированными результатами
* `Функция` Наблюдение по тексту узлов и необязательному разрешенному OCR, нажатия по ссылкам, ввод, прокрутка и клавиши с проверкой изменений экрана и доказательствами завершения
* `Функция` Сетевые и локальные модели через AutoJs6 без хранения учетных данных; отсутствие выбранной цели вызывает ошибку без скрытой замены модели
* `Функция` Бюджеты шагов, вызовов, времени и токенов, сроки инструментов, не более двух исправлений решения за шаг и защита от повторных бесполезных действий
* `Функция` Именованные пресеты и общие настройки моделей, контекста, инструментов, бюджетов, осторожного режима, папок и памяти; gesture/files/shell изначально выключены
* `Функция` Память предпочтений по области с отдельным одобрением предложений/импорта, правкой, удалением и копией JSON, до 500 записей / 256 KiB; автоматическая подстановка до 4 KiB
* `Функция` Подробности и хронология, фильтры, черновики повторного запуска и очищенный экспорт JSON, с частной историей до 200 задач / 32 MiB
* `Функция` Подтверждение по риску в панели, уведомлениях и плавающей карточке; платежи и память всегда одобряются отдельно; потеря хоста блокирует задачи, перезапуск не возобновляет их автоматически
* `Функция` Настройки, автономная история версий и правовые сведения на десяти языках; ручная проверка GitHub с отменой, суточным кэшем и игнорированием версий, без автоматического скачивания APK
* `Исправление` Области касания форм и фильтров, перенос текста списков и столбцов параметров скрипта, расположение плавающих элементов при крупном шрифте и на Android 7
* `Исправление` Обход проверки учётных данных в памяти предпочтений с помощью полноширинных символов, символов нулевой ширины и некоторых названий учётных данных
* `Исправление` Плавающая кнопка задач могла оставаться скрытой после пробуждения устройства без защитной блокировки, пока состояние экрана не установилось
* `Исправление` После завершения процесса плагина прерванные задачи отмечаются как неудачные; блокировка экрана останавливает последующие действия
* `Исправление` Файловые инструменты отклоняют обход каталогов, абсолютные и недопустимые рабочие пути до подтверждения или вызова хоста; история сохраняет ограниченные категории отказов без отклоненного текста модели
* `Исправление` Подтверждение возвращает целевое приложение перед продолжением действий, обрабатывает ответ после остановки экрана и сворачивает плавающую карточку перед выполнением
* `Исправление` Сбой запуска на Android 13 при чтении контроллера системных панелей до создания представления окна устранен
* `Исправление` История сортируется и сохраняется по времени начала задач, чтобы перезапись файлов при перезапуске не удаляла новые задачи
* `Исправление` Ответы и подтверждения проверяют владельца interaction, запрещая скриптам отвечать вместо интерфейса плагина
* `Исправление` Кнопки подтверждения транзакции требуют отдельного подтверждения платежа и не используют разрешения на всю задачу
* `Исправление` Совпадения вне экрана с пустыми или перевернутыми границами сохраняют текст и отмечают непригодные координаты вместо ошибки аргументов
* `Исправление` Повторный поиск узла различает границы и возможности действий, чтобы не путать вложенные контейнеры с целью
* `Исправление` Уточнены подсказки исправления целей узлов: сохранение префикса # и отсутствие snapshotId при использовании selector
* `Исправление` При приеме задачи правила заказов загружаются заранее без затратной компиляции
* `Исправление` Проверка различает узлы разных окон, сохраняет требование наблюдения после чтения буфера и не считает передачу файлов оплатой
* `Исправление` Отсутствие ответа при чтении экрана после действия больше не приводит к превышению срока ожидания стабильности
* `Исправление` Скрытие многострочных параметров до разбиения консоли на строки, без пропуска секретов при совпадении параметра с именем поля учетных данных
* `Исправление` Завершающаяся фоновая служба с уведомлением больше не отклоняет запуск следующей задачи
* `Улучшение` При сокращении длинной истории задачи повторно используются неизменные фрагменты инструкций и наблюдений, сокращая время обработки каждого шага
* `Улучшение` Размер описаний подтверждения учитывает экранирование JSON, чтобы большие таблицы параметров не превышали лимит событий Binder
* `Улучшение` Минимальный хост AutoJs6 6.8.0 / сборка 5289 обеспечивает проверку узлов действий и привязку подтверждения к выполнению
* `Зависимость` Добавлены common-plugin-api, host-capability-api и ai-agent-api из одной release-сборки AutoJs6 6.8.0 / 5289 (MPL 2.0), закреплены SHA-256
* `Зависимость` Добавлен Gson 2.13.2 для строгого ограниченного разбора JSON и деревьев схем
