⁨3-Stove Agent⁩ وكيل ينفذ العمليات على الهاتف نيابة عنك. بعد وصف الهدف بجملة واحدة, يراقب الشاشة عبر AutoJs6 وينقر ويكتب ويمرر خطوة بخطوة, أو يختار سكربتا مسجلا ويكمل معاملاته ثم يشغله, حتى يتحقق الهدف. تتطلب العمليات الحساسة مثل الدفع والإرسال والحذف تأكيدا قبل التنفيذ, ولكل مهمة حد لعدد الخطوات والمدة.

### البدء

1. ثبت [⁨3-Stone AI⁩](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI) وفعله, ثم أضف فيه نموذجا عبر الإنترنت أو استورد نموذجا محليا. يستدعي ⁨3-Stove Agent⁩ النماذج من خلاله.
2. افتح ⁨3-Stove Agent⁩. إذا أشارت الشاشة الرئيسية إلى عدم الاتصال, فانقر "الاتصال بـ AutoJs6".
3. انقر شارة النموذج في الشريط العلوي لاختيار نموذج, أو أبق "تلقائي" (يفضل النموذج المحلي).
4. اكتب الهدف في شريط الإدخال وانقر "بدء المهمة". تعرض بطاقة المهمة تقدم كل خطوة, وفيها أيضا تجيب عن الأسئلة وتؤكد العمليات.

### الميزات الرئيسية

- **المهام والسجل**: أثناء تنفيذ المهمة يمكنك عرض خطواتها والإجابة عن الأسئلة أو إيقافها في أي وقت. يحتفظ "سجل المهام" بالمهام المنتهية, ويمكن مشاركة ملخصها أو تشغيلها مرة أخرى (إعادة التشغيل تضع الهدف الأصلي في شريط الإدخال فقط لمراجعته قبل البدء).
- **التأكيدات وأذونات العمليات**: تنفذ عمليات القراءة فقط مباشرة, أما العمليات الحساسة مثل الدفع والإرسال والحذف وكتابة الملفات فتتطلب تأكيدا افتراضيا, ويمكن السماح بها مرة واحدة أو طوال المهمة الحالية. يتيح قسم "أذونات العمليات" في الإعدادات اختيار "قياسي" أو "حذر" أو "وصول كامل" (بلا تأكيد, مع علامة واضحة طوال تفعيله).
- **الإعدادات المسبقة**: احفظ مجموعات الأدوات والميزانيات والسياق الثابت التي تستخدمها كثيرا كإعداد مسبق, واختره من وسم الإعداد المسبق في شريط الإدخال قبل البدء. عند تفعيل "وضع الخطة" تعرض المهمة أولا خطة من 3 إلى 8 خطوات وتنفذها بعد المراجعة.
- **الذاكرة**: احفظ التفضيلات التي يجب أن يتذكرها الوكيل, فترفق بالمهام تلقائيا. لا تحفظ أي ذاكرة يقترحها الوكيل إلا بعد تأكيدها, ولا تحفظ كلمات المرور أو بيانات الاعتماد الأخرى في الذاكرة.
- **السكربتات المسجلة**: بعد إضافة تعليق `@agent` في بداية السكربت (انظر المثال أدناه) يستطيع الوكيل اختيار هذا السكربت وتشغيله. تضاف مواقع السكربتات خارج دليل العمل في "مجلدات السكربتات".
- **الكرة العائمة**: بعد تفعيلها في الإعدادات يمكنك إدخال الأهداف ومعالجة التأكيدات وإيقاف المهام فوق التطبيقات الأخرى.
- **البدء السريع**: شارك نصا مع ⁨3-Stove Agent⁩, أو استخدم اختصار الشاشة الرئيسية "مهمة جديدة", أو ثبت إعدادا مسبقا على الشاشة الرئيسية. هذه المداخل تنشئ مسودة فقط, ولا تنفذ إلا بعد النقر على "بدء المهمة".
- **الصوت**: بعد تشغيل "تفعيل الإدخال الصوتي" في الإعدادات يظهر ميكروفون بجانب مربع الإدخال, وإذا كان ⁨3-Macaw Speech⁩ مثبتا فيتم التعرف دون اتصال. يستقبل "الاستماع الدائم" (معطل افتراضيا) مهمة واحدة بعد التعرف على كلمة التنبيه "小炉小炉" أو "Hey Stove". نتائج الصوت أيضا تصبح مسودات فقط.
- **أدوات إضافية**: يمكن من الإعدادات تفعيل التعرف على النص (يتطلب إضافة OCR), والأدوات التي توفرها إضافات أخرى (مثل القراءة الصوتية والتفريغ في ⁨3-Macaw Speech⁩), والأدوات التي توفرها خوادم MCP, والسكربتات التي ينشئها النموذج ولا تنفذ إلا بعد المراجعة.

### الاستخدام في السكربتات

في سكربت AutoJs6 ابدأ مهمة باستخدام `ai.agent.run`, وتبقى الأسئلة والتأكيدات تعالج في واجهة ⁨3-Stove Agent⁩:

```js
let run = ai.agent.run('اقرأ إصدار Android وأبلغ بالقيمة المرصودة.', {
    tools: ['observe', 'user'],
    interaction: 'plugin',
    budget: { maxSteps: 8 },
});
run.on('progress', (event) => console.log(event.message));
run.result.then(
    (result) => console.log(result.status, result.summary),
    (error) => console.error(error.code, error.message),
);
```

- تحقق من `status` في النتيجة: حتى عند وفاء Promise قد تكون النتيجة `completed` أو `partial` أو `failed` أو `blocked` أو `cancelled`. استدع `run.cancel()` لإيقاف المهمة.
- أضف `preset: 'your-preset-name'` إلى الخيارات لاستخدام إعداد مسبق محفوظ, أو `plan: true` لتعرض المهمة خطة أولا.
- كل الخيارات والأحداث موضحة في [وثائق AutoJs6 > ai.agent](https://docs.autojs6.com/#/ai).

لكي يشغل الوكيل سكربتا خاصا بك, احفظ المثال التالي باسم `text-counter.js` في دليل عمل AutoJs6. بعد ذلك اطلب عد أحرف نص ما, وإذا نقصت معاملة فسيسأل الوكيل عنها أولا:

```js
/**
 * @agent
 * @description Count Unicode characters in the supplied text
 * @param {string} text Text to count
 * @risk readonly
 * @confirm never
 * @timeout 10000
 */
let context = ai.agent.context();
if (!context) throw Error('Start this registered script through 3-Stove Agent');
let text = new java.lang.String(context.parameters.text);
ai.agent.result({ characters: text.codePointCount(0, text.length()) });
```

### المتطلبات

- Android 7.0 أو أحدث, وAutoJs6 6.8.0 أو أحدث.
- يوفر [⁨3-Stone AI⁩](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI) النماذج, ولا يحفظ ⁨3-Stove Agent⁩ نفسه بيانات اعتماد النماذج.
- تستخدم عمليات الشاشة خدمة إمكانية الوصول في AutoJs6. تفعل تلقائيا عندما يكون Root أو الإعدادات الآمنة أو Shizuku مهيأ في AutoJs6, وإلا ففعلها يدويا وفق التلميح.
- يستخدم إذن الإشعارات للتأكيدات في الخلفية وتنبيهات المهام, وتتطلب الكرة العائمة إذن "الظهور فوق التطبيقات الأخرى".

### الأسئلة الشائعة

**سبب الحاجة إلى AutoJs6**

يتولى ⁨3-Stove Agent⁩ المهام والواجهة, بينما تمر استدعاءات النماذج وعمليات الشاشة وتشغيل السكربتات كلها عبر AutoJs6. دون الاتصال بـ AutoJs6 يمكن عرض السجل فقط ولا يمكن بدء مهمة جديدة, وانقطاع الاتصال يعيق المهمة الجارية, ولا تعاد تلقائيا بعد إعادة الاتصال.

**حالات طلب التأكيد عند الدفع**

افتراضيا يتطلب كل دفع تأكيدا مستقلا, والموافقة على طلب شراء أو عملية أخرى لا تعني الموافقة على الدفع, وانتهاء المهلة يعد رفضا. يتخطى "وصول كامل" تأكيدات الدفع, فلا تفعله إلا إذا كنت تثق بالهدف والنموذج.

**أسباب بطء النموذج المحلي أو عجزه عن إكمال المهمة**

تحميل النموذج بنجاح لا يعني قدرته على إكمال المهام, فابدأ بمهام بسيطة وراجع النتائج. على الهواتف القديمة قد يتجاوز الاستدعاء الأول حد 5 دقائق, وأثناء الانتظار تعرض لوحة المهام الثواني المنقضية, وتذكر نتيجة انتهاء المهلة الأسباب المحتملة والحلول.

**أسباب توقف الاستماع الدائم**

لا يبدأ الاستماع الدائم مع تشغيل الجهاز, ويستأنف عند فتح لوحة المهام أو الإعدادات. على ColorOS أو MIUI اسمح بالتشغيل التلقائي وأضف التطبيق إلى القائمة البيضاء للبطارية, وإلا فقد ينهي النظام الخدمة الدائمة, كما لا يمكن التعرف على كلمة التنبيه أثناء تسجيل تطبيق آخر للصوت.

قائمة الأدوات وصيغة تسجيل السكربتات وتفاصيل الأذونات موجودة في [صفحة المشروع](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stove-Agent).
