3-Stove Agent는 휴대폰에서 사용자를 대신해 조작을 수행하는 에이전트입니다. 목표를 한 문장으로 설명하면 AutoJs6를 통해 화면을 보면서 탭, 입력, 스크롤을 단계별로 수행하거나, 등록된 스크립트를 골라 매개변수를 채운 뒤 실행하여 목표를 달성할 때까지 진행합니다. 결제, 전송, 삭제 같은 민감한 조작은 실행 전에 확인이 필요하며, 각 작업에는 단계 수와 시간 제한이 있습니다.

### 시작하기

1. [3-Stone AI](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI)를 설치하고 사용 설정한 뒤, 그 안에서 온라인 모델을 추가하거나 로컬 모델을 가져옵니다. 3-Stove Agent는 이를 통해 모델을 호출합니다.
2. 3-Stove Agent를 엽니다. 홈 화면에 연결되지 않았다고 표시되면 "AutoJs6 연결"을 탭합니다.
3. 상단 바의 모델 칩을 탭해 모델을 선택하거나 "자동"으로 둡니다 (로컬 모델이 우선 사용됩니다).
4. 입력 바에 목표를 입력하고 "작업 시작"을 탭합니다. 작업 카드에 각 단계의 진행 상황이 표시되며, 질문에 답하거나 조작을 확인하는 것도 여기에서 처리합니다.

### 주요 기능

- **작업과 기록**: 작업이 진행되는 동안 단계를 확인하고, 질문에 답하거나 언제든지 중지할 수 있습니다. "작업 기록"에는 끝난 작업이 남아 요약을 공유하거나 다시 실행할 수 있습니다 (다시 실행하면 원래 목표가 입력 바에 채워질 뿐이며, 확인한 뒤 시작합니다).
- **확인과 작업 권한**: 읽기 전용 조작은 바로 실행되고, 결제, 전송, 삭제, 파일 쓰기 같은 민감한 조작은 기본적으로 먼저 확인합니다. 확인은 한 번만 허용하거나 이번 작업 동안 항상 허용할 수 있습니다. 설정의 "작업 권한"에서 "표준", "신중", "전체 접근" (확인 없음, 켜져 있는 동안 눈에 띄게 표시) 중에서 고를 수 있습니다.
- **프리셋**: 자주 쓰는 도구 그룹, 예산, 고정 컨텍스트를 프리셋으로 저장하고, 작업을 시작하기 전에 입력 바의 프리셋 태그에서 고릅니다. "계획 모드"를 켜면 작업이 먼저 3단계에서 8단계 사이의 계획을 제시하고, 검토한 뒤 실행합니다.
- **메모리**: 에이전트가 기억해야 할 선호 사항을 저장하면 작업을 시작할 때 자동으로 첨부됩니다. 에이전트가 제안한 메모리는 확인한 뒤에만 저장됩니다. 비밀번호 같은 자격 증명은 메모리에 저장하지 마세요.
- **등록 스크립트**: 스크립트 맨 앞에 `@agent` 주석을 추가하면 (아래 예시 참고) 에이전트가 그 스크립트를 골라 실행할 수 있습니다. 작업 디렉터리 밖의 스크립트 위치는 "스크립트 디렉터리"에서 추가합니다.
- **플로팅 볼**: 설정에서 켜면 다른 앱 위에서 목표를 입력하고, 확인을 처리하거나 작업을 중지할 수 있습니다.
- **빠른 시작**: 텍스트를 3-Stove Agent로 공유하거나, 홈 화면 바로가기 "새 작업"을 쓰거나, 프리셋을 홈 화면에 고정할 수 있습니다. 이러한 진입점은 초안만 만들며, "작업 시작"을 탭해야 실행됩니다.
- **음성**: 설정에서 "음성 입력 사용"을 켜면 입력란 옆에 마이크가 표시되고, 3-Macaw Speech가 설치되어 있으면 오프라인으로 인식합니다. "상시 듣기" (기본값은 꺼짐)는 호출어 "小炉小炉" 또는 "Hey Stove"를 인식한 뒤 작업 한 건을 받습니다. 음성 결과도 초안이 될 뿐입니다.
- **추가 도구**: 설정에서 텍스트 인식 (OCR 플러그인 필요), 다른 플러그인이 제공하는 도구 (예: 3-Macaw Speech의 낭독과 전사), MCP 서버가 제공하는 도구, 그리고 모델이 생성하고 검토한 뒤에만 실행되는 스크립트를 켤 수 있습니다.

### 스크립트에서 사용하기

AutoJs6 스크립트에서는 `ai.agent.run`으로 작업을 시작합니다. 질문과 확인은 계속 3-Stove Agent 화면에서 처리됩니다:

```js
let run = ai.agent.run('Android 버전을 읽고 실제로 관찰한 값을 보고하세요.', {
    tools: ['observe', 'user'],
    interaction: 'plugin',
    budget: { maxSteps: 8 },
});
run.on('progress', (event) => console.log(event.message));
run.result.then(
    (result) => console.log(result.status, result.summary),
    (error) => console.error(error.code, error.message),
);
```

- 결과의 `status`를 확인하세요. Promise가 이행되어도 결과는 `completed`, `partial`, `failed`, `blocked`, `cancelled` 중 하나일 수 있습니다. `run.cancel()`을 호출하면 작업을 중지할 수 있습니다.
- 옵션에 `preset: 'your-preset-name'`을 추가하면 저장된 프리셋을 쓰고, `plan: true`를 추가하면 작업이 먼저 계획을 제시합니다.
- 모든 옵션과 이벤트는 [AutoJs6 문서 > ai.agent](https://docs.autojs6.com/#/ai)를 참고하세요.

에이전트가 직접 만든 스크립트를 실행하게 하려면 아래 예시를 AutoJs6 작업 디렉터리에 `text-counter.js`로 저장하세요. 그런 다음 어떤 텍스트의 글자 수를 세어 달라고 요청하면, 매개변수가 부족할 때 에이전트가 먼저 묻습니다:

```js
/**
 * @agent
 * @description Count Unicode characters in the supplied text
 * @param {string} text Text to count
 * @risk readonly
 * @confirm never
 * @timeout 10000
 */
let context = ai.agent.context();
if (!context) throw Error('Start this registered script through 3-Stove Agent');
let text = new java.lang.String(context.parameters.text);
ai.agent.result({ characters: text.codePointCount(0, text.length()) });
```

### 요구 사항

- Android 7.0 이상, AutoJs6 6.8.0 이상.
- 모델은 [3-Stone AI](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI)가 제공하며, 3-Stove Agent 자체는 모델 자격 증명을 저장하지 않습니다.
- 화면 조작에는 AutoJs6의 접근성 서비스를 사용합니다. AutoJs6에 Root, 보안 설정, Shizuku 중 하나가 구성되어 있으면 자동으로 켜지고, 그렇지 않으면 안내에 따라 직접 켭니다.
- 알림 권한은 백그라운드 확인과 작업 알림에 쓰이며, 플로팅 볼에는 "다른 앱 위에 표시" 권한이 필요합니다.

### 자주 묻는 질문

**AutoJs6가 필요한 이유**

3-Stove Agent는 작업과 화면을 담당하고, 모델 호출, 화면 조작, 스크립트 실행은 모두 AutoJs6를 통해 이루어집니다. AutoJs6에 연결되지 않은 동안에는 기록만 볼 수 있고 새 작업을 시작할 수 없습니다. 연결이 끊기면 진행 중인 작업이 막히며, 다시 연결해도 자동으로 다시 실행되지 않습니다.

**결제에 확인이 필요한 경우**

기본적으로 결제마다 별도의 확인이 필요하며, 주문이나 다른 조작을 승인해도 결제는 승인되지 않고, 시간이 초과되면 거부로 처리됩니다. "전체 접근"은 결제 확인을 건너뛰므로 목표와 모델을 신뢰할 때만 켜세요.

**로컬 모델이 느리거나 작업을 완료하지 못하는 이유**

모델을 불러올 수 있다고 해서 작업을 완료할 수 있는 것은 아니므로, 간단한 작업부터 시작해 결과를 확인하세요. 오래된 휴대폰에서는 첫 호출이 5분 제한을 넘을 수 있습니다. 기다리는 동안 작업 화면에 경과한 초가 표시되며, 시간이 초과된 결과에는 가능한 원인과 대처 방법이 적힙니다.

**상시 듣기가 멈추는 이유**

상시 듣기는 기기 부팅 시 시작되지 않으며, 작업 화면이나 설정을 열면 다시 시작됩니다. ColorOS나 MIUI에서는 자동 시작을 허용하고 배터리 화이트리스트에 추가하세요. 그렇지 않으면 시스템이 상주 서비스를 종료할 수 있습니다. 다른 앱이 녹음하는 동안에는 호출어도 인식할 수 없습니다.

도구 목록, 스크립트 등록 형식, 권한 설명은 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stove-Agent)를 참고하세요.
