3-Stove Agent は, スマートフォン上の操作を代わりに行うエージェントです. 目標を一文で伝えると, AutoJs6 を通じて画面を確認しながらタップ, 入力, スクロールを段階的に行うか, 登録済みのスクリプトを選んでパラメーターを補って実行し, 目標を達成するまで続けます. 支払い, 送信, 削除などの重要な操作は実行前に確認が必要で, 各タスクにはステップ数と時間の上限があります.

### はじめに

1. [3-Stone AI](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI) をインストールして有効にし, そこでオンラインモデルを追加するかローカルモデルをインポートします. 3-Stove Agent はこれを通じてモデルを呼び出します.
2. 3-Stove Agent を開きます. ホーム画面に未接続と表示された場合は "AutoJs6 に接続" をタップします.
3. 上部バーのモデルチップをタップしてモデルを選ぶか, "自動" のままにします (ローカルモデルが優先されます).
4. 入力バーに目標を入力し, "タスクを開始" をタップします. タスクカードに各ステップの進行状況が表示され, 質問への回答や操作の確認もここで行います.

### 主な機能

- **タスクと履歴**: 実行中のタスクは, ステップの確認, 質問への回答, いつでも停止ができます. "タスク履歴" には終了したタスクが残り, 要約の共有や再実行ができます (再実行は元の目標を入力バーに戻すだけで, 確認してから開始します).
- **確認と操作の権限**: 読み取り専用の操作はそのまま実行され, 支払い, 送信, 削除, ファイルの書き込みなどの重要な操作は既定で確認が必要です. 確認は 1 回だけ許可するか, このタスクの間は常に許可できます. 設定の "操作の権限" では "標準", "慎重", "フルアクセス" (確認なし, 有効な間は目立つ表示あり) を選べます.
- **プリセット**: よく使うツールグループ, 予算, 固定コンテキストをプリセットとして保存し, 開始前に入力バーのプリセットタグから選びます. "計画モード" を有効にすると, タスクはまず 3 から 8 ステップの計画を示し, 確認後に実行します.
- **メモリ**: エージェントに覚えておいてほしい好みを保存すると, タスク開始時に自動で添付されます. エージェントが提案したメモリは確認後にのみ保存されます. パスワードなどの認証情報はメモリに保存しないでください.
- **登録スクリプト**: スクリプトの先頭に `@agent` コメントを追加すると (下の例を参照), エージェントがそのスクリプトを選んで実行できます. 作業ディレクトリ以外のスクリプトの場所は "スクリプトディレクトリ" で追加します.
- **フローティングボール**: 設定で有効にすると, 他のアプリの上で目標の入力, 確認の処理, タスクの停止ができます.
- **クイックスタート**: テキストを 3-Stove Agent に共有する, ホーム画面のショートカット "新規タスク" を使う, プリセットをホーム画面に固定する, のいずれかで始められます. これらの入口は下書きを作るだけで, "タスクを開始" をタップすると実行されます.
- **音声**: 設定で "音声入力を有効にする" をオンにすると入力欄の横にマイクが表示され, 3-Macaw Speech がインストールされていればオフラインで認識します. "常時待ち受け" (既定ではオフ) はウェイクワード "小炉小炉" または "Hey Stove" を認識した後にタスクを 1 つ受け付けます. 音声の結果も下書きになるだけです.
- **その他のツール**: 設定では, 文字認識 (OCR プラグインが必要), 他のプラグインのツール (3-Macaw Speech の読み上げや文字起こしなど), MCP サーバーのツール, モデルが生成し確認後にのみ実行されるスクリプトを有効にできます.

### スクリプトでの使い方

AutoJs6 のスクリプトでは `ai.agent.run` でタスクを開始します. 質問と確認は引き続き 3-Stove Agent の画面で処理されます:

```js
let run = ai.agent.run('Android のバージョンを読み取り, 観察した値を報告してください.', {
    tools: ['observe', 'user'],
    interaction: 'plugin',
    budget: { maxSteps: 8 },
});
run.on('progress', (event) => console.log(event.message));
run.result.then(
    (result) => console.log(result.status, result.summary),
    (error) => console.error(error.code, error.message),
);
```

- 結果の `status` を確認してください. Promise が履行されても, 結果は `completed`, `partial`, `failed`, `blocked`, `cancelled` のいずれかになり得ます. `run.cancel()` を呼ぶとタスクを停止できます.
- オプションに `preset: 'your-preset-name'` を加えると保存済みのプリセットを使い, `plan: true` を加えるとタスクがまず計画を示します.
- すべてのオプションとイベントは [AutoJs6 ドキュメント > ai.agent](https://docs.autojs6.com/#/ai) を参照してください.

エージェントに独自のスクリプトを実行させるには, 次の例を AutoJs6 の作業ディレクトリに `text-counter.js` として保存します. その後, あるテキストの文字数を数えるよう依頼すると, パラメーターが足りない場合はエージェントが先に尋ねます:

```js
/**
 * @agent
 * @description Count Unicode characters in the supplied text
 * @param {string} text Text to count
 * @risk readonly
 * @confirm never
 * @timeout 10000
 */
let context = ai.agent.context();
if (!context) throw Error('Start this registered script through 3-Stove Agent');
let text = new java.lang.String(context.parameters.text);
ai.agent.result({ characters: text.codePointCount(0, text.length()) });
```

### 動作要件

- Android 7.0 以降, AutoJs6 6.8.0 以降.
- モデルは [3-Stone AI](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI) が提供し, 3-Stove Agent 自体はモデルの認証情報を保存しません.
- 画面操作には AutoJs6 のアクセシビリティサービスを使います. AutoJs6 に Root, 安全な設定, Shizuku のいずれかが設定されていれば自動でオンになり, それ以外の場合は案内に従って手動でオンにします.
- 通知の権限はバックグラウンドでの確認とタスクの通知に使います. フローティングボールには "他のアプリの上に表示" の権限が必要です.

### よくある質問

**AutoJs6 が必要な理由**

3-Stove Agent はタスクと画面を担当し, モデルの呼び出し, 画面操作, スクリプトの実行はすべて AutoJs6 を通じて行われます. AutoJs6 に接続していない間は履歴を見られますが, 新しいタスクは開始できません. 接続が切れると実行中のタスクは妨げられ, 再接続しても自動では再実行されません.

**支払いに確認が必要な場合**

既定では支払いのたびに個別の確認が必要で, 注文や他の操作を承認しても支払いは承認されず, 時間切れは拒否として扱われます. "フルアクセス" は支払いの確認を省略するため, 目標とモデルを信頼できる場合にのみ有効にしてください.

**ローカルモデルが遅い, またはタスクを完了できない理由**

モデルを読み込めてもタスクを完了できるとは限らないため, 簡単なタスクから始めて結果を確認してください. 古いスマートフォンでは最初の呼び出しが 5 分の制限を超えることがあります. 待機中はタスク画面に経過秒数が表示され, タイムアウトした結果には考えられる原因と対処が記載されます.

**常時待ち受けが止まる理由**

常時待ち受けは端末の起動時には開始せず, タスク画面か設定を開くと再開します. ColorOS や MIUI では自動起動を許可し, バッテリーのホワイトリストに追加してください. そうしないとシステムが常駐サービスを終了することがあります. 他のアプリが録音している間はウェイクワードも認識できません.

ツールの一覧, スクリプトの登録形式, 権限の詳細は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stove-Agent) を参照してください.
