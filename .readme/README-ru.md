### Введение

******

AI Agent превращает цель на естественном языке в действия на Android-устройстве с AutoJs6. Он либо выбирает скрипт, который пользователь зарегистрировал для агента, заполняет его параметры и запускает; либо наблюдает экран через дерево узлов специальных возможностей и действует шаг за шагом (наблюдать, решать, действовать, проверять), пока цель не достигнута, не потребуется подтверждение или не исчерпан бюджет. Это ответ на [обсуждение AutoJs6 #577](https://github.com/SuperMonster003/AutoJs6/discussions/577).

Плагин одновременно является плагином AutoJs6 и самостоятельным приложением. Скрипты обращаются к нему через API `ai.agent` в AutoJs6; пользователи работают с ним через собственное рабочее пространство задач, панель AutoJs6, плавающую кнопку, системное меню отправки, ярлыки приложения и голосовой ввод. Вызовы модели и действия на устройстве всегда проходят через AutoJs6 по Binder: хост предоставляет плагину брокер модели (плагины AI Provider, уже известные хосту, например 3-Stone AI) и брокер возможностей с ограниченным разрешением. Плагин никогда не хранит учетные данные, не привязывается к поставщику модели самостоятельно и не запрашивает разрешение специальных возможностей.

### Возможности

******

Текущая реализация предоставляет следующие возможности:

- Выбор скриптов: скрипты, зарегистрированные через `project.json` или заголовочный комментарий `@agent`, представляются модели с описаниями и схемами параметров; агент выбирает один из них, заполняет параметры, при необходимости запрашивает подтверждение, запускает его в AutoJs6 и читает структурированный результат.
- Пошаговое управление экраном: агент наблюдает дерево узлов специальных возможностей в компактном текстовом виде (и текст экрана через плагин OCR, если он установлен), затем нажимает, вводит, прокручивает и использует клавиши через брокер возможностей AutoJs6, пока не сможет проверить достижение цели.
- Безопасность по замыслу: инструменты только для чтения выполняются автоматически, чувствительные действия (оплата, отправка, удаление, запись файлов, shell, жесты по координатам, скрипты, зарегистрированные как чувствительные) требуют подтверждения, а у каждого запуска есть бюджеты по шагам, вызовам модели, длительности и токенам.
- API скриптов и пользовательский интерфейс: `ai.agent.run(goal, options)` возвращает дескриптор `AgentRun` с событиями, ответами и отменой; самостоятельное приложение предлагает рабочее пространство задач с историей, пресетами, памятью предпочтений, настройками и историей выпусков.

### Установка

******

1. Установите APK плагина со страницы [Releases](https://github.com/SuperMonster003/AutoJs6-Plugin-AI-Agent/releases) на устройство с AutoJs6 сборки 5293 или новее.
2. Откройте центр плагинов AutoJs6, убедитесь, что `AI Agent` распознан, и включите его. Официальные пакеты автоматически проходят проверку подписи.

Установите и включите [3-Stone AI](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI), затем настройте в нем сетевую модель или импортируйте поддерживаемую локальную. Текущий посредник хоста выбирает 3-Stone AI; другой Provider требует интеграции в хост. Модель выбирается в AI Agent > Пресеты. Connected to AutoJs6 показывает подключение к хосту; выбор модели находится в пресетах.

### Совместимость

Android 7.0+ (API 24). Подключение требует AutoJs6 6.8.0 / build 5289+; полный API задач и этот пример требуют build 5293+. Используйте сборку с изменениями Agent. Для действий на экране включите службу специальных возможностей хоста. OCR необязателен и требует установленного, разрешенного и доступного по данным хоста плагина. AI Agent не хранит учетные данные моделей и не имеет собственной службы специальных возможностей.

### Запуск из интерфейса

Откройте AI Agent, подключите AutoJs6, введите цель и запустите с настройками по умолчанию. Отвечайте и подтверждайте действия в карточке; открывайте недавние задачи для просмотра.

### Запуск из скрипта

Выполните этот JavaScript в AutoJs6 после подключения AI Agent и настройки модели. Вопросы и подтверждения обрабатывает интерфейс плагина. Для сохраненной конфигурации добавьте `preset: "your-preset-name"` в параметры.

```javascript
let run = ai.agent.run('Прочитай версию Android и сообщи наблюдаемое значение.', {
    tools: ['observe', 'user'],
    interaction: 'plugin',
    budget: { maxSteps: 8 },
});
run.on('progress', (event) => console.log(event.message));
run.result.then(
    (result) => console.log(result.status, result.summary),
    (error) => console.error(error.code, error.message),
);
```

Проверяйте `result.status`: исполненный Promise может содержать completed, partial, failed, blocked или cancelled. `run.cancel()` останавливает задачу. Выбор модели, события, бюджеты и ответы скрипта описаны в [ai.agent API](https://docs.autojs6.com/#ai).

### Регистрация скрипта

Сохраните пример как `text-counter.js` в рабочей папке AutoJs6 или каталоге, одобренном хостом. Начальный JSDoc с `@agent` регистрирует файл. Попросите подсчитать символы в заданном тексте; недостающие обязательные параметры будут запрошены перед запуском.

```javascript
/**
 * @agent
 * @description Count Unicode characters in the supplied text
 * @param {string} text Text to count
 * @risk readonly
 * @confirm never
 * @timeout 10000
 */
let context = ai.agent.context();
if (!context) throw Error('Start this registered script through AI Agent');
let text = new java.lang.String(context.parameters.text);
ai.agent.result({ characters: text.codePointCount(0, text.length()) });
```

Также можно поместить этот `project.json` рядом с `main.js`, который читает `ai.agent.context().parameters` и вызывает `ai.agent.result(...)`, как выше. Регистрация проекта находится в объекте `agent`.

```json
{
  "name": "Text counter",
  "main": "main.js",
  "agent": {
    "id": "text-counter",
    "description": "Count Unicode characters in the supplied text",
    "parameters": {
      "type": "object",
      "properties": { "text": { "type": "string" } },
      "required": ["text"],
      "additionalProperties": false
    },
    "risk": "readonly",
    "confirm": "never",
    "timeoutMs": 10000
  }
}
```

Поддерживаются string, number, integer и boolean; вложенные объекты и массивы не поддерживаются. Скрипты sensitive всегда требуют подтверждения до запуска. Регистрируйте только проверенные скрипты: декларация риска не изолирует JavaScript. [Полный формат](https://github.com/SuperMonster003/AutoJs6/blob/master/docs/dev/agent-script-manifest-v1.md).

### Пресеты и память

Откройте предустановки на экране задач для сохранения настроек. Имена служат постоянными идентификаторами в скриптах и памяти; для другого имени создайте копию. Встроенную default можно изменять, но нельзя удалять. Выберите модель из каталога хоста или автоматический выбор. Если выбранная модель недоступна, задача завершится ошибкой без замены модели. Параметры задачи могут только сужать ограничения. Постоянный контекст и контекст задачи вместе ограничены 8 KiB. Память может включать общие записи и записи текущей предустановки, только одну область или быть отключена. Изменение и удаление не влияют на задачи в очереди. Личное хранилище: до 32 предустановок / 1 MiB.

Откройте память для просмотра, изменения, удаления или резервного копирования предпочтений. До 500 записей / 256 KiB с областью, исходной задачей и датами. Подтверждайте каждый memory_propose и каждую импортируемую запись. Сначала создайте отсутствующие профили. Автоматически добавляются целые новейшие записи разрешенной области, до 4 KiB; текущий профиль имеет приоритет при совпадении ключей. memory: false отключает только автоматическое добавление. Чтобы запретить запросы и предложения, отключите группу memory или область памяти. Экспорт содержит реальные значения и происхождение. Не храните учетные данные; распознаваемые ключи и форматы токенов отклоняются.

### Использование

- Укажите дополнительные папки в разделе "Каталоги скриптов" стартового экрана, по одному абсолютному пути в строке. Хост проверяет и применяет сохраненные пути; задачи могут только сузить разрешенную область.
- До 200 задач / 32 MiB. Сначала удаляются завершенные задачи, которые дольше всего не просматривались. Повторный запуск заполняет исходную цель и набор настроек на панели. Проверьте их и нажмите кнопку запуска. Очистка истории сохраняет текущие задачи. Экспорт сохраняет счетчики, имена инструментов и подтверждения. Цели, параметры, наблюдения и результаты скриптов удаляются. Выберите место сохранения.
- На переднем плане отвечайте в задачах, в фоне открывайте приоритетное уведомление конкретного запроса. Подтверждение показывает инструмент, параметры, риск и оставшееся время. Повторное разрешение действует только для этого инструмента с этим риском в текущей задаче; платежи и память всегда подтверждаются отдельно. Запоминание ответа создает отдельный memory_propose в разрешенной области. Подтверждение обычно ждет 120 секунд, вопрос до 10 минут, в рамках бюджета задачи. Истечение срока возвращает USER_TIMEOUT; модель может переспросить или сообщить о частичном выполнении. Старые запросы не отвечают на новые. Уведомления зависят от разрешений и каналов.
- В настройках из экрана задач выберите группы, бюджет, осторожный режим, голосовой ввод и профиль по умолчанию. Изменения действуют для новых задач. gesture/files/shell изначально выключены; OCR требует доступного разрешенного плагина хоста. Пустой бюджет наследует исходные значения, настройки ограничены протоколом. Профили и параметры задачи могут только сужать лимиты. Управление данными показывает число записей и байты; очистка категории требует подтверждения и отсутствия активных задач. Очистка профилей восстанавливает default. Также доступны папки скриптов, лицензии и исходный код.
- История выпусков и правовые сведения доступны без сети. Проверка GitHub Releases запускается вручную, успешный ответ хранится 24 часа. Есть отмена и игнорирование версии. Диалог открывает внутреннюю историю или страницу выпуска в браузере. Автоматических проверок и загрузки APK нет.
- Включите плавающую кнопку в настройках, разрешите показ поверх приложений и сохраните. По умолчанию она выключена и видна только при подключении AutoJs6, скрывается при блокировке или отключении. Служба переднего плана не работает в простое. Перетащите кнопку или нажмите для ввода цели, выбора пресета, ответа и остановки. Сворачивание карточки возвращает уведомления подтверждения. Отправьте обычный текст, используйте ярлык новой задачи или закрепите пресет с необязательной целью. Все входы открывают редактируемый черновик и требуют явного запуска. Удаленные пресеты не заменяются автоматически. Распознавание речи использует язык интерфейса, скрыто при недоступности и заполняет текст без отправки.

### Частые вопросы

**Зачем нужен AutoJs6?**

Плагин управляет циклом задачи и интерфейсом. AutoJs6 предоставляет модели, действия специальных возможностей и запуск зарегистрированных скриптов. Без совместимого подключенного хоста история доступна, но новые задачи на устройстве не запускаются. Потеря хоста блокирует активные задачи; переподключение не повторяет их автоматически.

**Почему требуется подтверждение каждой оплаты?**

Оплата является отдельным чувствительным действием. Одобрение заказа, скрипта или похожих действий не разрешает оплату. Каждое обнаруженное действие оплаты требует отдельного подтверждения; истечение срока означает отказ. Перед одобрением проверьте продавца, товары, адрес и сумму.

**Каковы ограничения локальных моделей?**

Задачи зависят от следования инструкциям, корректного JSON решений и доступного контекста. Небольшая модель может загрузиться, но не справиться с задачей; записанный случай Wi-Fi для Gemma 4 E2B IT не прошел проверку решений. Начинайте с коротких задач и проверяйте partial/failed. 1.0.0 использует текст узлов/OCR и цикл JSON; зрение, нативные вызовы инструментов и генерация скриптов остаются в плане 1.1.0.

### Разрешения и безопасность

******

Плагин соблюдает явные границы:

- Контрактные входы Binder защищены разрешением подписи org.autojs.permission.PLUGIN. Лаунчер (включая ярлыки) и приемник text/plain ACTION_SEND публичны и принимают только ограниченные черновики цели/пресета. Внешний Intent не запускает задачи, не подтверждает действия и не меняет разрешения. Настройки, голосовые результаты и управление приватны.
- Плагин не хранит ключи API, никогда не привязывается к поставщику модели и не запрашивает разрешение специальных возможностей: вызовы модели и действия на устройстве проходят через брокеры, которые AutoJs6 предоставляет для одной подключенной связи и отзывает при отключении, каждый из которых ограничен разрешением (допустимые методы, частота, размеры, квота модели).
- INTERNET нужен только для ручной проверки выпусков GitHub. FOREGROUND_SERVICE и FOREGROUND_SERVICE_SPECIAL_USE поддерживают активные задачи, POST_NOTIFICATIONS показывает ход и подтверждения. SYSTEM_ALERT_WINDOW запрашивается только при включении плавающей кнопки в настройках. Разрешения специальных возможностей, хранилища и микрофона не запрашиваются.
- История задач, пресеты и память предпочтений остаются в закрытом хранилище плагина; резервное копирование и перенос между устройствами отключены.

Получайте плагин только со страницы официальных [Releases](https://github.com/SuperMonster003/AutoJs6-Plugin-AI-Agent/releases) или из центра плагинов AutoJs6. Пакеты из неизвестных источников могут не пройти проверку хоста или нести риски, даже если номер версии выглядит одинаково.

### Интерфейс плагина

******

Следующая информация предназначена разработчикам хоста AutoJs6 и плагинов; хост использует эти идентификаторы для обнаружения плагина и согласования совместимости:

```text
application id: io.github.supermonster003.autojs6.plugin.ai.agent
plugin id: ai-agent
engine: ai-agent
variant: default
service action: org.autojs.plugin.AI_AGENT
service category: ai-agent
service process: :agent
info action: org.autojs.plugin.INFO
aidl interface: org.autojs.plugin.ai.agent.api.IAiAgentPlugin
minimum host build: 5289 (6.8.0)
```

`AiAgentPluginService` / `IAiAgentPlugin` / `IAiAgentLink`: Проверка хоста при подключении, очередь задач, ответы, отмена, запросы и закрытая история шагов; задачи блокируются при потере хоста и не возобновляются после перезапуска процесса.

### Сборка и проверка

******

Этот раздел предназначен разработчикам, желающим собрать плагин из исходного кода; обычные пользователи могут просто установить готовый APK со страницы Releases.

Собрать отладочный APK:

```powershell
.\gradlew.bat :app:assembleDebug
```

Запустить модульные тесты JVM и собрать APK инструментальных тестов:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebugAndroidTest
```

Собрать выпускной APK:

```powershell
.\gradlew.bat :app:assembleRelease
```

Собрать выпускной артефакт и добавить версию и контрольную сумму CRC32 к имени файла:

```powershell
.\gradlew.bat :app:appendDigestToReleasedFiles
```

Проверить, что источники многоязычной документации и сгенерированные артефакты синхронизированы (также проверяется в CI):

```powershell
py .python\generate_markdown.py --check
```

Для сборки требуются JDK 21 или новее и Android SDK 37; версии Gradle и плагинов централизованно управляются через `version.properties` и `io.github.supermonster003.autojs6-platform-versions`.
