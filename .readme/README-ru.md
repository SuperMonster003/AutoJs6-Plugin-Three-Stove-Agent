### Введение

******

3-Stove Agent превращает цель на естественном языке в действия на Android-устройстве с AutoJs6. Он либо выбирает скрипт, который пользователь зарегистрировал для агента, заполняет его параметры и запускает; либо наблюдает экран через дерево узлов специальных возможностей и действует шаг за шагом (наблюдать, решать, действовать, проверять), пока цель не достигнута, не потребуется подтверждение или не исчерпан бюджет. Это ответ на [обсуждение AutoJs6 #577](https://github.com/SuperMonster003/AutoJs6/discussions/577).

3-Stove Agent предлагает отдельную панель задач и плагин AutoJs6 через ai.agent. Встроенные действия и вызовы модели проходят через хост. MCP использует только серверы, настроенные пользователем. Прямого подключения к Provider и разрешения специальных возможностей нет.

### Состояние

******

Версия 1.2.0 приносит необязательные инструменты MCP, нативные вызовы, наблюдение по снимкам и генерируемые скрипты; она проверена на пяти реальных устройствах и на эмуляторах API 24 / 35 / 36.1. Известные ограничения: небольшие локальные модели (Gemma 4 E2B / E4B) принимают решения плохо; сбои после переключения сети VPN при стандартном автоподключении остаются нерешенными; полная визуальная задача между UID не принята, AiGoCode gpt-5.6-sol прошел только проверки исходного изображения и изображения в результате инструмента. Подробности в [ROADMAP.md](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stove-Agent/blob/master/ROADMAP.md).

### Возможности

******

Текущая реализация предоставляет следующие возможности:

- Выбор скриптов: скрипты, зарегистрированные через `project.json` или заголовочный комментарий `@agent`, представляются модели с описаниями и схемами параметров; агент выбирает один из них, заполняет параметры, при необходимости запрашивает подтверждение, запускает его в AutoJs6 и читает структурированный результат.
- Пошаговое управление экраном: агент наблюдает дерево узлов специальных возможностей в компактном текстовом виде (и текст экрана через плагин OCR, если он установлен), затем нажимает, вводит, прокручивает и использует клавиши через брокер возможностей AutoJs6, пока не сможет проверить достижение цели.
- Безопасность по замыслу: инструменты только для чтения выполняются автоматически, чувствительные действия (оплата, отправка, удаление, запись файлов, shell, жесты по координатам, скрипты, зарегистрированные как чувствительные) по умолчанию требуют подтверждения, а у каждого запуска есть бюджеты по шагам, вызовам модели, длительности и токенам. Подтверждение можно дать один раз или до конца задачи; в настройках также есть осторожный режим и полный доступ, который пропускает подтверждения и заметно отмечается. Список платежных приложений и таблицу чувствительных ключевых слов можно расширить на экране настроек Распознавание рисков; встроенные записи нельзя удалить.
- API скриптов и пользовательский интерфейс: `ai.agent.run(goal, options)` возвращает дескриптор `AgentRun` с событиями, ответами и отменой; самостоятельное приложение предлагает рабочее пространство задач с историей, пресетами, памятью предпочтений, настройками и историей выпусков.
- Нативные вызовы через хост: схемы каталога, проверка всего пакета, последовательное выполнение, отдельные подтверждения, передача результатов и общий журнал шагов
- Наблюдение по снимкам через AutoJs6 на Android 11+: screen_capture уменьшает длинную сторону до 1280 и использует JPEG с качеством 70, с визуальными инструкциями, учетом токенов изображений и вложениями в результаты нативных инструментов
- Созданный JavaScript через script_run_source: группа script_dynamic изначально отключена. Каждый вызов показывает краткий и раскрываемый полный код для одобрения один раз или до конца задачи; полный доступ пропускает эту проверку. Поддерживаются тайм-аут, отмена, структурированный результат и закрытая запись кода. Код UTF-8 и его строка JSON ограничены 8 KiB каждый.
- Выбранные инструменты локальных или внешних серверов MCP с отдельным уровнем риска; группа mcp изначально выключена
- Отдельное приложение переработано на Material 3: главный экран стал лентой задач с полем ввода над клавиатурой, в верхней панели есть капсула модели, история и меню (Новая задача, Предустановки, Память, Папки скриптов, Серверы MCP, Настройки), баннер подключения показывается только пока AutoJs6 не подключен, хронология шагов обновляется по шагам, а Запустить снова только заполняет поле ввода. Настройки разделены на понятные разделы, светлая и темная темы согласованы

### Установка

******

1. Установите APK плагина со страницы [Releases](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stove-Agent/releases) на устройство с AutoJs6 сборки 5293 или новее.
2. В центре плагинов AutoJs6 проверьте, что `3-Stove Agent` распознан. Официальные пакеты проходят проверку подписи и включаются после установки без подтверждения; явно отключенный плагин остается отключенным. Центр плагинов является единственным переключателем. Скрипты и интерфейс подключаются по запросу, без запуска при загрузке и повторения прежних задач.

Установите и включите [3-Stone AI](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stone-AI), затем настройте в нем сетевую модель или импортируйте поддерживаемую локальную. Текущий посредник хоста выбирает 3-Stone AI; другой Provider требует интеграции в хост. Модель выбирается капсулой модели на главном экране 3-Stove Agent. Баннер там появляется, только пока AutoJs6 не подключен.

### Совместимость

Android 7.0+ (API 24). Требуется хост AutoJs6 6.8.0 / build 5298+, который уже содержит все изменения, нужные API задач (build 5293+), нативным вызовам и вводу изображений (build 5297+). Для действий на экране нужна служба специальных возможностей хоста; Agent сначала запускает ее способом, настроенным в AutoJs6 (Root, защищенные настройки или Shizuku), и просит включить ее вручную только при неудаче. OCR необязателен и требует установленного, разрешенного и доступного по данным хоста плагина. 3-Stove Agent не хранит учетные данные моделей и не имеет собственной службы специальных возможностей.

### Запуск из интерфейса

Откройте 3-Stove Agent, подключите AutoJs6, введите цель и запустите задачу. Капсула модели на главном экране выбирает сетевую или локальную модель либо режим Автоматически (сначала модель на устройстве, иначе первая доступная). Ищите модели, закрепляйте избранные и используйте недавние; значки показывают заявленную поддержку инструментов и изображений. Экран задач и плавающая кнопка используют этот выбор для новых задач, не меняя профили и текущую задачу; профили больше не содержат модель. Необязательный профиль выбирается кнопкой профиля в поле ввода. Отвечайте на вопросы и следите за ходом работы в карточке задачи.

### Запуск из скрипта

Выполните этот JavaScript в AutoJs6 после подключения 3-Stove Agent и настройки модели. Вопросы и подтверждения обрабатывает интерфейс плагина. Для сохраненной конфигурации добавьте `preset: "your-preset-name"` в параметры. Добавьте `plan: true`, чтобы задача сначала предложила план на проверку.

```javascript
let run = ai.agent.run('Прочитай версию Android и сообщи наблюдаемое значение.', {
    tools: ['observe', 'user'],
    interaction: 'plugin',
    budget: { maxSteps: 8 },
});
run.on('progress', (event) => console.log(event.message));
run.result.then(
    (result) => console.log(result.status, result.summary),
    (error) => console.error(error.code, error.message),
);
```

Проверяйте `result.status`: исполненный Promise может содержать completed, partial, failed, blocked или cancelled. `run.cancel()` останавливает задачу. Выбор модели, события, бюджеты и ответы скрипта описаны в [ai.agent API](https://docs.autojs6.com/#ai).

### Регистрация скрипта

Сохраните пример как `text-counter.js` в рабочей папке AutoJs6 или каталоге, одобренном хостом. Начальный JSDoc с `@agent` регистрирует файл. Попросите подсчитать символы в заданном тексте; недостающие обязательные параметры будут запрошены перед запуском.

```javascript
/**
 * @agent
 * @description Count Unicode characters in the supplied text
 * @param {string} text Text to count
 * @risk readonly
 * @confirm never
 * @timeout 10000
 */
let context = ai.agent.context();
if (!context) throw Error('Start this registered script through 3-Stove Agent');
let text = new java.lang.String(context.parameters.text);
ai.agent.result({ characters: text.codePointCount(0, text.length()) });
```

Также можно поместить этот `project.json` рядом с `main.js`, который читает `ai.agent.context().parameters` и вызывает `ai.agent.result(...)`, как выше. Регистрация проекта находится в объекте `agent`.

```json
{
  "name": "Text counter",
  "main": "main.js",
  "agent": {
    "id": "text-counter",
    "description": "Count Unicode characters in the supplied text",
    "parameters": {
      "type": "object",
      "properties": { "text": { "type": "string" } },
      "required": ["text"],
      "additionalProperties": false
    },
    "risk": "readonly",
    "confirm": "never",
    "timeoutMs": 10000
  }
}
```

Поддерживаются string, number, integer и boolean; вложенные объекты и массивы не поддерживаются. Скрипты sensitive требуют подтверждения до запуска, кроме режима полного доступа. Регистрируйте только проверенные скрипты: декларация риска не изолирует JavaScript. [Полный формат](https://github.com/SuperMonster003/AutoJs6/blob/master/docs/dev/agent-script-manifest-v1.md).

### Пресеты и память

Откройте предустановки на экране задач для сохранения настроек. Имена служат постоянными идентификаторами в скриптах и памяти; для другого имени создайте копию. Встроенную default можно изменять, но нельзя удалять. Предустановки не содержат модель; модель, сохраненная прежней версией, остается только для скриптов. Параметры задачи могут только сужать ограничения. Постоянный контекст и контекст задачи вместе ограничены 8 KiB. Память может включать общие записи и записи текущей предустановки, только одну область или быть отключена. Изменение и удаление не влияют на задачи в очереди. Личное хранилище: до 32 предустановок / 1 MiB. Предустановки можно экспортировать в JSON и импортировать с проверкой каждой по отдельности; файл не содержит модель, а отсутствующие на этом устройстве группы инструментов и каталоги скриптов при импорте отбрасываются. В режиме плана модель сначала предлагает от 3 до 8 шагов, которые вы проверяете и можете изменить до выполнения, а когда план перестает подходить, предлагает новый; по умолчанию режим выключен.

Откройте память для просмотра, изменения, удаления или резервного копирования предпочтений. До 500 записей / 256 KiB с областью, исходной задачей и датами. Подтверждайте каждый memory_propose и каждую импортируемую запись. Сначала создайте отсутствующие профили. Автоматически добавляются целые новейшие записи разрешенной области, до 4 KiB; текущий профиль имеет приоритет при совпадении ключей. memory: false отключает только автоматическое добавление. Чтобы запретить запросы и предложения, отключите группу memory или область памяти. Экспорт содержит реальные значения и происхождение. Не храните учетные данные; распознаваемые ключи и форматы токенов отклоняются.

### Использование

- Укажите дополнительные папки в разделе "Каталоги скриптов" стартового экрана, по одному абсолютному пути в строке. Хост проверяет и применяет сохраненные пути; задачи могут только сузить разрешенную область.
- До 200 задач / 32 MiB. Сначала удаляются завершенные задачи, которые дольше всего не просматривались. Повторный запуск заполняет исходную цель и набор настроек на панели. Проверьте их и нажмите кнопку запуска. Очистка истории сохраняет текущие задачи. Экспорт сохраняет счетчики, имена инструментов и подтверждения. Цели, параметры, наблюдения и результаты скриптов удаляются. Выберите место сохранения. Пункт "Поделиться сводкой" на странице деталей передает системной панели отправки цель, состояние, сводку, доказательства и незавершенную работу, но не наблюдения.
- На переднем плане отвечайте в задачах, в фоне открывайте приоритетное уведомление конкретного запроса. Подтверждение показывает инструмент, параметры, риск и оставшееся время. Всегда разрешать в этом сеансе одобряет тот же инструмент с тем же риском до конца задачи, включая последующие предложения памяти и созданный код; оплата требует отдельного разрешения. Запоминание ответа создает отдельный memory_propose в разрешенной области. Подтверждение обычно ждет 120 секунд, вопрос до 10 минут, в рамках бюджета задачи. Истечение срока возвращает USER_TIMEOUT; модель может переспросить или сообщить о частичном выполнении. Старые запросы не отвечают на новые. Уведомления зависят от разрешений и каналов.
- В настройках из экрана задач выберите группы, бюджет, разрешения операций (стандарт, осторожный режим или полный доступ), голосовой ввод и профиль по умолчанию. Каждое изменение сохраняется сразу и действует для новых задач. Полный доступ выполняет включенные инструменты, включая оплату, без подтверждения; пока он включен, экран задач, плавающая кнопка и история показывают предупреждение. gesture/files/shell/script_dynamic изначально выключены; OCR требует доступного разрешенного плагина хоста. Лимит в режиме Авто использует исходное значение, длительность вводится в минутах, настройки ограничены протоколом. Профили и параметры задачи могут только сужать лимиты. Управление данными показывает число записей и байты; очистка категории требует подтверждения и отсутствия активных задач. Очистка профилей восстанавливает default. Профили, память, папки скриптов и серверы MCP также открываются из настроек. Оповещения о задачах объединяют ошибки и завершения в две строки с кратким описанием и независимым выбором уведомления, toast и диалога. По умолчанию для ошибок включены все три, для завершений уведомление и toast; сохраненный выбор остается. Штатное завершение, включая частичный результат без ошибки, оповещает один раз; отмена и просмотр истории молчат. На рабочем экране чип доступа переключает разрешения операций напрямую, чип пресета открывает лист выбора и управления пресетами, а меню включает плавающий шар.
- Откройте настройки через меню справа вверху. Язык, темная тема и цвет могут следовать AutoJs6 или задаваться отдельно. Язык и тема также могут следовать Android. История версий и правовые сведения доступны без сети. Успешные ручные проверки GitHub кешируются на 24 часа. Автопроверка по умолчанию выключена. После включения она выполняется только при использовании приложения, не чаще раза в 12 часов, без уведомлений об ошибках и игнорируемых версиях и без загрузки APK. Управление игнорируемыми обновлениями позволяет вернуть уведомления по отдельным версиям. Экран О приложении показывает версию, разработчика, исходный код, лицензию и сторонние уведомления. Унифицированы плоские группы настроек, строки и скругленные диалоги по центру. Язык, ночной режим, цвет и значок меняются только после подтверждения; отмена сохраняет прежние значения. Цвет по умолчанию следует AutoJs6, доступны общая палитра, HEX/RGB и локальный предпросмотр. Нейтральный фон остается постоянным, элементы следуют теме. По умолчанию выбран автоматический адаптивный значок, обновление сохраняет явный выбор.
- Включите плавающую кнопку в настройках и разрешите показ поверх приложений. По умолчанию она выключена и видна только при подключении AutoJs6, скрывается при блокировке или отключении. Служба переднего плана не работает в простое. Перетащите кнопку или нажмите для ввода цели, выбора пресета, ответа и остановки. Сворачивание карточки возвращает уведомления подтверждения. Отправьте обычный текст, используйте ярлык новой задачи или закрепите пресет с необязательной целью. Все входы открывают редактируемый черновик и требуют явного запуска. Удаленные пресеты не заменяются автоматически. Распознавание речи использует язык интерфейса, скрыто при недоступности и заполняет текст без отправки.

### Частые вопросы

**Зачем нужен AutoJs6?**

Плагин управляет циклом задачи и интерфейсом. AutoJs6 предоставляет модели, действия специальных возможностей и запуск зарегистрированных скриптов. Без совместимого подключенного хоста история доступна, но новые задачи на устройстве не запускаются. Потеря хоста блокирует активные задачи; переподключение не повторяет их автоматически.

**Когда требуется подтверждение оплаты?**

Оплата является отдельным чувствительным действием. Одобрение заказа, скрипта или другого действия не разрешает оплату. По умолчанию каждое обнаруженное действие оплаты требует отдельного подтверждения; истечение срока означает отказ. Выбор Всегда разрешать в этом сеансе в запросе оплаты разрешает только последующие оплаты этим инструментом в той же задаче. Полный доступ пропускает подтверждение оплаты, поэтому включайте его только для целей и моделей, которым доверяете. Перед одобрением проверьте продавца, товары, адрес и сумму.

**Каковы ограничения локальных моделей?**

Загрузка модели не гарантирует успех задачи. Записанная проверка решений Wi-Fi для Gemma 4 E2B IT не пройдена; эта цель сохраняет JSON. Нативные вызовы также требуют совместимых хоста и цели, с проверкой аргументов, подтверждениями и бюджетами. Начните с небольших задач и проверяйте partial/failed. Изображения требуют поддерживающей их цели; AiGoCode gpt-5.6-sol прошел проверки с исходным изображением и изображением в результате инструмента, другие цели требуют отдельной проверки. Созданные скрипты требуют явного включения, а каждый исходный код следует правилам подтверждения.

### Разрешения и безопасность

******

Плагин соблюдает явные границы:

- Список разрешений: org.autojs.permission.PLUGIN (точки входа контракта хоста), FOREGROUND_SERVICE и FOREGROUND_SERVICE_SPECIAL_USE (служба переднего плана во время задачи), POST_NOTIFICATIONS (фоновые подтверждения и уведомления о ходе), INTERNET (ручная или автоматическая проверка выпусков GitHub и подключение к настроенным пользователем серверам MCP), ACCESS_LOCAL_NETWORK (запрашивается только из настроек MCP на Android 17+), SYSTEM_ALERT_WINDOW (запрашивается только при включении плавающего шарика в настройках). Разрешения специальных возможностей, хранилища и микрофона не запрашиваются, а трафик модели никогда не проходит через плагин.
- Контрактные входы Binder защищены разрешением подписи org.autojs.permission.PLUGIN. Лаунчер (включая ярлыки) и приемник text/plain ACTION_SEND публичны и принимают только ограниченные черновики цели/пресета. Внешний Intent не запускает задачи, не подтверждает действия и не меняет разрешения. Настройки, голосовые результаты и управление приватны.
- 3-Stove Agent предлагает отдельную панель задач и плагин AutoJs6 через ai.agent. Встроенные действия и вызовы модели проходят через хост. MCP использует только серверы, настроенные пользователем. Прямого подключения к Provider и разрешения специальных возможностей нет.
- Учетные данные модели остаются у Provider, вызовы идут через AutoJs6. Токены MCP Bearer шифруются Android Keystore в закрытом хранилище и не входят в запросы модели или экспорт истории. INTERNET также нужен настроенным серверам MCP; Android 17+ запрашивает доступ к локальной сети из настроек MCP. Исходный риск сервера: SENSITIVE. Отмена не откатывает удаленные действия; ошибочные вызовы автоматически не повторяются.
- История задач, пресеты и память предпочтений остаются в закрытом хранилище плагина; резервное копирование и перенос между устройствами отключены.
- Снимки передаются через AutoJs6 выбранной модели, которая может работать в сети. Экран должен быть включен и разблокирован. История хранит размеры и число байтов, без содержимого изображений. JSON сохраняет текущее изображение до нового наблюдения или ответа. Нативный диалог хранит прежние изображения в пределах лимитов пакета и сеанса, повторно резервируя токены для каждого раунда.
- Созданные скрипты работают с разрешениями AutoJs6 без песочницы JavaScript и могут действовать вне включенных групп. Полный код хранится в закрытых шагах с обычными правилами удаления паролей и хранения истории. Код, измененный после обнаружения пароля, нельзя сохранить как исходный. Проверяйте .js перед передачей другим.
- Полный доступ включается только в закрытых настройках плагина; вывод модели, содержимое экрана, запросы скриптов и внешние Intent не могут включить или расширить его. Он пропускает подтверждения включенных инструментов, включая оплату, но не включает дополнительные группы и сохраняет бюджеты и разрешения хоста. Специальные возможности запускает хост способом, настроенным в AutoJs6; сам плагин по-прежнему не запрашивает разрешение специальных возможностей.

Получайте плагин только со страницы официальных [Releases](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stove-Agent/releases) или из центра плагинов AutoJs6. Пакеты из неизвестных источников могут не пройти проверку хоста или нести риски, даже если номер версии выглядит одинаково.

- `Функция` Нативные вызовы через хост: схемы каталога, проверка всего пакета, последовательное выполнение, отдельные подтверждения, передача результатов и общий журнал шагов
- `Функция` Наблюдение по снимкам через AutoJs6 на Android 11+: screen_capture уменьшает длинную сторону до 1280 и использует JPEG с качеством 70, с визуальными инструкциями, учетом токенов изображений и вложениями в результаты нативных инструментов
- `Функция` Созданный JavaScript через script_run_source: группа script_dynamic изначально отключена. Каждый вызов требует просмотра краткого и раскрываемого полного кода с отдельным одобрением. Поддерживаются тайм-аут, отмена, структурированный результат и закрытая запись кода. Код UTF-8 и его строка JSON ограничены 8 KiB каждый.
- `Зависимость` Обновление трех release-артефактов API хоста до AutoJs6 52ce694f92 / build 5297 для согласуемого ввода изображений с сохранением базового контракта подключения build 5289+

### Сборка и проверка

******

Этот раздел предназначен разработчикам, желающим собрать плагин из исходного кода; обычные пользователи могут просто установить готовый APK со страницы Releases.

Собрать отладочный APK:

```powershell
.\gradlew.bat :app:assembleDebug
```

Запустить модульные тесты JVM и собрать APK инструментальных тестов:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebugAndroidTest
```

Собрать выпускной APK:

```powershell
.\gradlew.bat :app:assembleRelease
```

Собрать выпускной артефакт и добавить версию и контрольную сумму CRC32 к имени файла:

```powershell
.\gradlew.bat :app:appendDigestToReleasedFiles
```

Проверить, что источники многоязычной документации и сгенерированные артефакты синхронизированы (также проверяется в CI):

```powershell
py .python\generate_markdown.py --check
```

Для сборки требуются JDK 21 или новее и Android SDK 37; версии Gradle и плагинов централизованно управляются через `version.properties` и `io.github.supermonster003.autojs6-platform-versions`.

### Локализация и генерация документации

******

```text
.readme/common.json
.readme/lang_*.json
.readme/template_readme.md
.readme/template_plugin_instruction.md
.changelog/lang_*.json
.changelog/template_changelog.md
.python/generate_markdown.py
app/src/main/assets/doc/CHANGELOG-*.md
app/src/main/res/raw-*/plugin_instruction.md
```

Языковые JSON-файлы в `.readme/` и `.changelog/` являются единственным источником README, инструкций центра плагинов и журнала изменений. Всегда редактируйте эти JSON-источники и перезапускайте `py .python/generate_markdown.py`; сгенерированные README, `plugin_instruction.md` и журнал изменений никогда не правятся вручную. Запустите `py .python/generate_markdown.py --check`, чтобы проверить все сгенерированные артефакты.
