- JVM 364/364, API 28 和 API 37 / 16 KiB 插件 instrumentation 各 31/31.
- debug / androidTest / release R8 / lint 构建通过, 10 语言 36 项生成文档校验通过.
- 宿主 `b93a1194a6` 补齐旧支付检查夹具的 `orderStatus=none`; API 37 三项夹具通过. 这是合成正确性回归, 不是实际支付页面证据.

- harness 处理已启用服务的重绑, 保留其他无障碍服务的 Unicode 组件名, 回复以临时文件 + 重命名发布. 选择题回复必须与选项完全相同; 不合约回复记录拒绝而非取消整个任务. 这些是测试驱动修正, 不扩大生产插件权限.

## 5. AVD 存储恢复

用户已下载模型但无法导入. AVD 配置显示扩大容量, 实际 userdata qcow2 基础层与覆盖层仍为 6 GiB, Android 文件系统也未扩大. 关机后完整备份配置, userdata 两层和加密密钥两层, 再将虚拟磁盘扩大至 16 GiB. 在线文件系统扩容因 resize inode 元数据异常失败, 停止 Android 服务并卸载数据分区后执行离线检查/修复/扩容, 随后重新启动.
