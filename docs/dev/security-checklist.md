# P7 安全审计清单

审计日期: 2026-09-25. 范围为 AI Agent 1.0.0 的生产代码, 合并清单, 本地存储, 导出和宿主边界. 真实模型能力, 界面可用性和整库宿主 lint 分别保留在对应 gate, 不由本清单替代.

## 权限和入口

- [x] 权限仅为 PLUGIN, INTERNET, FOREGROUND_SERVICE, FOREGROUND_SERVICE_SPECIAL_USE, POST_NOTIFICATIONS, SYSTEM_ALERT_WINDOW. INTERNET 只供用户主动检查固定 GitHub 发行接口; 无模型 HTTP 接入, 无存储/麦克风/无障碍/安装/开机广播权限.
- [x] 导出组件枚举: WakeActivity, AiAgentPluginInfoService, AiAgentPluginService 受 PLUGIN 权限保护; LauncherActivity 和 ShareTargetActivity 只接受待审核草稿. 其余 Activity, 本地 Binder 服务和任务前台服务全部不导出. 无 Provider 或清单 Receiver. `ManifestContractTest` 增加完整导出集合断言.
- [x] Launcher/分享/快捷方式只读取有限字段, 严格限制纯文本大小, 去除 spans, 不转发 ClipData 和任意 extras, 不自动开始任务或接受外部确认回复. 已删除预设不会静默回退. 既有 TaskEntry/Workbench 测试覆盖非法入口和一次手动开始只产生一个任务.
- [x] 宿主接口每次核对调用 UID, 实际安装的宿主包名/最低版本/当前签名集合; 链路再核对所属 UID. 私有管理端点只接受同 UID. 权限声明本身不替代身份校验.
- [x] 宿主附着广播核对 action, 显式宿主包名及不可变 PendingIntent 的 creatorPackage/creatorUid/可信签名. 缺失/错误类型/外来身份拒绝, 正向生产广播已在六台设备通过. 身份令牌不发送执行, 不存储. 详见 P7 conformance 和 compatibility 证据.

## 内容, 记忆和导出

- [x] 生产 Kotlin 源码没有 Log/println/printStackTrace/Timber 正文输出. 提示词, 模型应答, 原始观察, 目标和记忆值不进普通应用日志; 调试 E4 原始证据只存忽略目录和应用私有文件. 宿主 toast 正文泄露已由 P7 grant 阶段修复.
- [x] 模型目录只含公开 targetId/可用性/能力信息. Agent 不读取 Provider 配置或凭据, 不存储 API key; 凭据继续归 Provider 管理. 记忆对象的 toString 只报告值的字节数.
- [x] 记忆提议, 手动编辑, 导入和持久化读取共用 MemoryCodec. 审计复现了普通 note 键下的全角/零宽凭据赋值, OTP/多语言验证码和部分 token/key 名称漏检. 现在只规范化用于检查的副本, 共用凭据名称策略, 拒绝可识别赋值及 token/PEM 形态, 保存的正常偏好原文保持不变.
- [x] 新回归验证提议入口共用的校验器和导入拒绝, 并验证被拒绝的编辑不改写既有磁盘字节, 发布快照或重启后的偏好. 旧实现两项新回归均失败, 修复后通过. 现有含非法条目的存储继续失败关闭, 不清空或偷偷修复用户文件.
- [x] RunHistoryExport 使用输出字段白名单, 目标/预设/决策/参数/观察/结果正文均替换, 只保留合法状态/工具名/错误分类和计数. 自由文本不依赖正则脱敏. 既有存储和真实跨 Binder 导出测试覆盖私密 canary 与未知字段.
- [x] 记忆备份是用户主动选择的可恢复 JSON, 与诊断历史导出不同: 明确提示包含偏好值和来源任务 ID, 经确认后由 SAF 选择目的地. 不把它声称为已脱敏文件, 不自动分享, 导入逐条审核. 它仍受凭据内容校验约束.
- [x] 应用内部存储, 备份关闭及云备份/设备迁移全域排除保持有效. 大型私有返回值使用有界, 只读, 已取消路径链接的描述符. 错误和跨 UID 调用关闭携带的 FD, 不泄露路径.

凭据检测的边界: 普通偏好文字与未知随机字符串可能无法在语义上区分, 因此本清单不把识别名单视为通用秘密检测器. 产品只支持偏好记忆, 不支持凭据保存; 所有记忆写入仍需用户逐项确认. 本次修复覆盖已复现的具体编码和名称绕过, 不宣称能识别任意秘密.

## 确认和执行

- [x] 预设只允许 default/cautious, 工具组与宿主 grant 取交集, 预算只能在有效上限内收紧. 未知策略/字段被拒绝. 预设和固定上下文不产生新授权.
- [x] 风险来自可信宿主节点/脚本元数据, 不能由模型参数降级. 敏感操作须确认, 支付动作每次确认且不提供 RUN 范围授权; 已授予的普通或敏感同类权限不能覆盖付款. 10 语言付款关键词和两种策略均有回归.
- [x] 记忆提议和强制脚本确认不允许 RUN 范围. requestId/所属任务/所属交互方/截止时间校验阻止过期通知和脚本任务被界面代答. 只有当前可见请求抑制其通知; 折叠或离开恢复入口.
- [x] 确认 Activity/展开悬浮卡使用 FLAG_SECURE; 通知为 PRIVATE 并提供不含目标正文的公开版本. PendingIntent 均不可变. 确认界面返回目标应用后才提交动作回复.
- [x] 敌意输入, 禁用工具, grant 越界, 旧连接回调, 取消竞争及进程死亡均有 P7 既有拒绝证据. 重连不恢复旧任务或未完成动作, 无后台自动支付路径.
