# P9.2 宿主图片协议与模型代理

本轮完成原 P9.2 的宿主条目, 沿用维护者已确认的 V2 家族内协商 2.1 方案.
未增加/分拆/丢弃路线图阶段. 3-Stone AI 在线模型映射和 Agent 截图工具仍是原有待办,
当前插件尚不能执行完整视觉任务. P9.1 Wi-Fi 双路径失败记录保持原结论.

## 行为与边界

- 宿主协商 2.0-2.1; 2.0 文本编码与 AIDL 顺序保持兼容. 图片需要 Provider 和具体
  target 同时支持 vision, 不会静默丢弃图片或切换模型.
- Agent 基础契约仍 V1, 通过 visionVersion=1 发现图片扩展. generate 的 imageRefs
  与原生工具结果均可携带 JPEG/PNG PFD, 并保留原请求, 回调, 轮次和截止时间.
- 文本与图片限额独立. 每批最多 4 张, 单张 4 MiB, 每批 8 MiB; 每边最多 4096,
  总像素最多 16777216; 初始输入和工具续轮合计最多 16 张 / 32 MiB. 逐项验证长度,
  摘要, MIME, 实际尺寸, 可解码性与 FD 引用. 协商可收紧限额.
- 图片 token 估算参与准入和无 usage 时的结算; 每次续轮计入历史保留图片, 实际
  累计 usage 到达后替换估算. 估算不保证等于具体模型的计费规则.
- 取消, 超时, 非法/深层嵌套 Bundle, 外部 UID, 空回调及链路关闭均清理图片描述符;
  工具续轮等到实际派发才打开出站 FD. 普通日志不含图片字节, base64, 摘要或文件路径.
- 本轮没有新建公开 JS 图片 API. 持久 ai.session, 图像生成, 音频和视频未纳入此条目.
